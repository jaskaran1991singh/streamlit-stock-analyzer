# **streamlit-stock-analyzer**
A Streamlit dashboard to analyze stock performance and annual reports. Select a pre-listed stock, upload your own report, or search for one. Get 3-year performance trends, pricing, financial summaries, buy/sell recommendations, and chat with the annual report for deeper insights.


## Description
A user-friendly Streamlit dashboard designed for seamless stock and financial analysis. The app allows you to:

### 1.Stock and Annual Report Selection:

Pick a stock and its associated annual report for a pre-selected company.
Upload your own annual report or search for a specific company's report.

### 2.Performance Analysis:

Analyze stock performance over the last three years with detailed insights.
Generate pricing trends, financial summaries, and technical overviews.

### 3.Buy/Sell Recommendation:

Receive actionable buy and sell recommendations based on the analyzed data.

### 4.Chat with the Annual Report:

Engage in an interactive chat to query and understand specific details from the annual report of the selected company.
This dashboard is perfect for investors, analysts, and finance enthusiasts seeking detailed insights and AI-powered interactivity with corporate financials.

## Key Features:
* Interactive Visualizations: Charts and graphs for performance and trends.
* AI-Powered Chat: Ask questions about the annual report and get precise answers.
* Custom Upload Support: Analyze reports for companies beyond the pre-selected ones.
* Streamlined UI: Simplified navigation and user-centric design for financial insights.


## Tech Stack:
* Frontend: Streamlit
* Data Analysis: Pandas, NumPy, Plotly
* NLP for Chat: OpenAI's GPT model
* Data Sources: Integrated with APIs for stock and financial data

Clone the repository and follow the instructions in the README.md to set up and launch your dashboard.
